# Garagem Clássica - Portal de Carros Antigos 🚗

Projeto acadêmico desenvolvido para a disciplina **DFEW.08 – Projeto Front-End para Web** da **Universidade Positivo**.

Professor: Fabricio Olivo (<fabricio@up.edu.br>)

---

## 📁 Estrutura de Pastas e Arquivos

```text
projeto-front/
├── index.html            (Página Inicial)
├── historia.html         (História - HTML/CSS Puro)
├── curiosidades.html     (Curiosidades - HTML/CSS/JS Puro)
├── modelos.html          (Modelos Famosos - CSS Flexbox)
├── galeria.html          (Galeria de Fotos - CSS Grid)
├── tabela.html           (Ficha Técnica - Tabela 6x6)
├── multimidia.html       (Reprodutores Nativos de Áudio e Vídeo)
├── cadastro.html         (Minha Garagem - DOM + LocalStorage)
├── contato.html          (Formulário com Validações Nativas)
├── sobre.html            (Sobre o Projeto e Equipe)
├── css/
│   ├── bootstrap.min.css (Bootstrap 5 local para offline)
│   └── styles.css        (Estilização própria com Grid, Flexbox e estados)
├── js/
│   ├── bootstrap.bundle.min.js (Bootstrap JS local)
│   └── script.js         (JavaScript puro: DOM, 4 estruturas, localStorage)
├── img/                  (Imagens e ilustrações vetoriais dos carros)
├── video/                (Vídeo MP4 com controles nativos)
├── audio/                (Áudio WAV com ronco de motor clássico)
└── doc/
    ├── documentacao.md   (Documentação acadêmica completa)
    └── documentacao.html (Versão formatada para leitura e impressão)
```

---

## 🚀 Como Executar Offline

1. Baixe ou clone o repositório.
2. Dê um duplo clique no arquivo `index.html` na raiz da pasta.
3. O site abrirá imediatamente em qualquer navegador (Google Chrome, Firefox, Safari ou Edge) sem precisar de internet ou servidor web.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<video>`, `<audio>`
- **CSS3:** Grid Layout, Flexbox, seletores de tag, classe, id e pseudo-classes (`:hover`, `:focus`, `:invalid`)
- **JavaScript Puro:** Manipulação do DOM, eventos, array de objetos, loops, condicionais e `localStorage`
- **Bootstrap 5 (Local):** Sistema de grid, botões e classes utilitárias
