Sobre o Projeto Front-End Web

Este website foi desenvolvido como avaliação prática da disciplina de Desenvolvimento Front-End para Web da Universidade Positivo.

Objetivo Geral

Construir um portal web temático, totalmente responsivo e interativo sobre Carros Antigos (Antigomobilismo), aplicando boas práticas de desenvolvimento front-end com HTML5 Semântico, CSS3 (Grid e Flexbox), JavaScript puro para controle dinâmico do DOM e armazenamento local com localStorage, além de componentes Bootstrap.

Tecnologias Utilizadas

  • HTML5: Estrutura semântica (header, nav, main, section, article, footer, video, audio).
  • CSS3: Estilização em 3 níveis (externo, incorporado e em linha), seletores por tag, classe e ID, Grid Layout, Flexbox e Media Queries.
  • JavaScript: Manipulação do DOM, eventos, localStorage e as 4 estruturas básicas de programação.
  • Bootstrap 5: Componentes visuais utilitários, cards, sistema de grid e botões.
